# 归档机器人 - 快速归档命令手册
## 简介
> 本文档详细描述了归档机器人的快速归档命令。这些命令允许管理员对特定的帖子进行标记，以使其在下一次自动归档周期中被优先处理。所有命令均以 `/优先归档` 作为根命令。
### 工作原理
> 该组命令通过一个“优先归档列表”来工作。被添加到列表中的帖子，在下一次自动归档扫描时，会被系统赋予一个极早的“上次活跃时间”（通过设定的权重值实现, 为 UnixEpoch 起始时间减去权重值）。这会使其在排序中排在最前面，从而被优先归档。这是一种间接但高效的快速优先归档方式。
### 权限模型
> 与 `/admin` 命令类似，`/优先归档` 组下的`添加`、`移除`、`查看列表`命令需要管理员权限。操作发起者必须拥有在配置文件 `appsettings.jsonc` 的 `AuthConfig.AdminRoleIds` 数组中定义的任一身份组ID。
## 命令详解
### 5. 添加优先归档 (`/优先归档 添加`)
> 此命令用于将一个帖子加入优先归档列表，以加速其归档进程。
> - 功能描述:
>   为一个指定的帖子添加优先归档标记。一旦添加，该帖子将在下一次自动归档任务运行时被赋予极高的归档优先级。如果目标帖子已存在于列表中，此命令将更新其权重和原因。
> - 执行前提:
>   1. 操作发起者必须拥有管理员权限。
>   2. 目标帖子必须位于当前服务器内，不能添加其他服务器的帖子。
> - 参数:
>   - `链接` (字符串, 必需): 目标帖子的完整Discord链接 (例如: `https://discord.com/channels/12345/67890`)。
>   - `原因` (字符串, 必需): 将此帖子加入优先归档列表的原因，方便后续追溯。
>   - `权重` (整数, 必需): 一个正整数，用于决定归档的优先级。值越高，归档优先级越高。有效范围为 `1` 至 `65535`。
> - 使用示例:
```
/优先归档 添加 链接:https://discord.com/channels/123.../456... 原因:帖子内容已过时 权重:100
```
> - 执行结果:
>   - 成功: 返回操作成功的确认信息。如果帖子是首次添加，会提示“添加成功”；如果已存在，则提示“已更新该贴权重”。数据将被持久化。
>   - 失败:
>     - 若权限不足、帖子链接格式错误、权重值超出范围、或尝试添加其他服务器的帖子，操作将失败并返回相应错误提示。
>     - 若根据链接无法找到帖子（可能已被删除），操作也会失败。
### 6. 移除优先归档 (`/优先归档 移除`)
> 此命令用于将一个帖子从优先归档列表中移除，使其恢复正常的归档逻辑。
> - 功能描述:
>   将一个已标记的帖子从优先归档列表中移除。移除后，该帖子将根据其实际的最后活动时间参与归档排序。
> - 执行前提:
>   - 操作发起者必须拥有管理员权限。
> - 参数:
>   - `链接` (字符串, 必需): 目标帖子的完整Discord链接。
> - 使用示例:
```
/优先归档 移除 链接:https://discord.com/channels/123.../456...
```
> - 执行结果:
>   - 成功: 返回操作成功的确认信息。数据将被持久化。
>   - 失败:
>     - 若权限不足或帖子链接格式错误，操作将失败。
>     - 若目标帖子原本就不在优先归档列表中，操作将失败并提示“移除失败”。
### 7. 查看优先归档列表 (`/优先归档 查看列表`)
> 此命令用于展示当前所有被标记为优先归档的帖子。
> - 功能描述:
>   查询并以嵌入式消息（Embed）的形式展示当前完整的优先归档列表。列表会按权重从高到低排序，并包含帖子的链接、权重、原因、添加人等详细信息。
> - 执行前提:
>   - 操作发起者必须拥有管理员权限。
> - 参数: 无
> - 使用示例:
```
/优先归档 查看列表
```
> - 执行结果:
>   - 成功:
>     - 若列表不为空，返回一个包含所有优先归档帖子详情的列表。如果内容过多，将自动进行分页显示。
>     - 若列表为空，返回提示信息，告知当前没有帖子在优先归档列表中。
>   - 失败:
>     - 若权限不足，操作将失败。
### 8. 检查目标帖子 (`/优先归档 检查目标帖子`)
> 此命令允许任何用户查询一个特定帖子是否处于优先归档状态。
> - 功能描述:
>   检查一个给定的帖子链接是否在当前的优先归档列表中，并返回其状态。
> - 执行前提:
>   - 操作发起者必须在机器人已配置的服务器内，但无需管理员权限。
> - 参数:
>   - `链接` (字符串, 必需): 需要查询的帖子的完整Discord链接。
> - 使用示例:
```
/优先归档 检查目标帖子 链接:https://discord.com/channels/123.../456...
```
> - 执行结果:
>   - 查询到: 返回一个绿色的嵌入式消息，确认该帖子在列表中，并显示其权重、原因、添加人等详细信息。
>   - 未查询到: 返回一个蓝色的嵌入式消息，告知该帖子不在优先归档列表中。
>   - 失败:
>     - 若用户不在已配置的服务器内执行命令，或提供的链接格式不正确，操作将失败。
